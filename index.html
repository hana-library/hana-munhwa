📋 데이터 출처 · 저작권 · API 운영 정책

1. 공공데이터 출처 및 원문 연결 원칙

본 서비스는 예술경영지원센터 KOPIS 공연예술통합전산망 오픈API 및 각 국공립 미술관·박물관·공연장의 공개 일정을 안내하며, 모든 항목은 원본 상세·예매 페이지로 직접 연결됩니다.

2. 공식 포스터 저작권 존중 및 무왜곡 표시

모든 포스터 이미지의 저작권은 원 주최·제작사 및 해당 문화기관에 귀속됩니다. 임의 합성 이미지를 사용하지 않으며, 미수신 시 정갈한 에디토리얼 타이포그래피 카드로 대체 표시합니다.

3. 기준일 자동 정렬 및 클라이언트 저장 정책

사용자 접속 시점의 오늘 날짜를 기준으로 진행중·개막 임박 일정을 자동 우선 정렬하며, 사용자가 등록한 포스터 캐시는 브라우저 로컬 스토리지에만 보관됩니다.
