1. 공공데이터 출처 및 원문 이동 원칙

본 서비스는 KOPIS 공연예술통합전산망, 국공립 미술관·박물관 및 문화예술회관의 공개 일정 정보를 큐레이션하며, 모든 카드에서 주최 기관의 공식 원본 페이지로 즉시 이동할 수 있습니다.

2. 공식 포스터 저작권 존중 및 무왜곡 표시

공식 포스터 아트워크의 저작권은 각 주최 기관 및 원저작권자에게 귀속됩니다. 공식 포스터가 수신된 경우 원본 비율을 훼손하지 않고 표시하며, 미수신 항목에는 임의의 그림을 합성하지 않고 행사 정보 중심의 타이포그래피 카드를 제공합니다.

3. 공개 배포 보안 및 인증키 비저장 원칙

GitHub Pages 등 정적 웹 배포 환경에서의 보안을 위해 소스 코드에는 어떠한 API 인증키도 포함되지 않습니다. 사용자가 입력한 KOPIS 인증키는 서버로 전송되지 않고 오직 본인 브라우저의 로컬 저장소(localStorage)에만 보관됩니다.

4. 실시간 기준일 자동 갱신

페이지를 열거나 새로고침할 때마다 접속 시점의 실제 날짜를 기준으로 진행중·개막예정 상태와 가까운 날짜순 정렬이 자동으로 재계산됩니다.
